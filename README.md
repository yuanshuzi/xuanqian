# 玄签 1.7 · 梅花易数取象

> 奶油纸与钴蓝配色 · 中英文双语 · 本地多文件运行

一个无需账号、无需后端的梅花易数取象网页。输入所问与时间，或选择已有卦象、随机取数、数字起卦，即可查看本卦、互卦、变卦、动爻、体用关系与取象建议。

- **版本**：1.7 xuanqian
- **入口文件**：`index.html`
- **运行方式**：浏览器直接打开，无需安装依赖或启动服务；`data/`、`assets/` 需与 `index.html` 保持同级
- **最后更新**：2026-11-24

---

## 快速开始

1. 找到项目目录 `E:\public\xuanqian`。
2. 双击 `index.html`，或右键选择「打开方式」并使用 Chrome / Edge。
3. 在「选择你的起卦方式」中选择一种模式。
4. 填写所问内容，点击「开始推演」。
5. 页面会展示取象时段、三卦卦盘、五行关系、象意简析与动爻取意。

推荐使用较新的 Chrome、Edge 或 Safari。农历日期转换依赖浏览器内置的 `Intl` 中国历法支持。

## 功能概览

- **四种起卦方式**：时起卦、卦象分析、随机起卦、数字起卦。
- **完整卦盘**：本卦、互卦、变卦的上卦与下卦，以及动爻位置。
- **体用分析**：按动爻确定体卦与用卦，显示五行生克、月令旺衰与互卦/变卦关系。
- **择时与取象**：给出参考时段、方位与适合的室内场景，只作文化取象，不作确定性预测。
- **推荐地点**：按「本卦取形、变卦取用」生成——本卦上卦给外在空间之形，下卦给近身坐处之形；变卦上卦给用事，下卦给身姿。
- **卦象类象**：结果下方「象与应」区按本卦上下卦、变卦上下卦四条，列出各卦的象、形、物、人、动、方位。
- **外应观察**：按卦给出优先留意的外应门类与记录要点，附强 / 中 / 弱 / 无四档使用强度。
- **万事类卦**：把所问自动归入十四类事项之一（工作、求财、交易、感情、家宅、出行、联系、失物、健康、争议、饮食、器物、天气等），给出取象、外应与判断框架。
- **爻辞原文**：动爻卡片显示本卦卦辞、该动爻原文，并列出六爻全文、高亮动爻。
- **中英文切换**：界面、卦名、动态分析、爻辞取意同步翻译；原典类象与外应条目保留中文原文。
- **双语示例**：内置抽卡、面试、出行、创作、沟通、学习 6 个示例，点击即可填入。
- **语言记忆**：语言选择保存在本地，刷新后继续保持。
- **响应式布局**：适配桌面和手机宽度，无横向溢出。
- **隐私优先**：所有推演在浏览器本地完成，不上传所问内容。
- **轻量交互**：星仪支持拖动和方向键旋转；尊重系统的「减少动态效果」设置。

## 四种起卦方式

| 模式 | 需要输入 | 起卦规则 |
| --- | --- | --- |
| 01 时起卦 | 所问之事与时间 | 以农历年支、农历月日、时支取数 |
| 02 卦象分析 | 本卦、互卦、变卦、动爻 | 直接按输入展示，并校验三卦关系 |
| 03 随机起卦 | 可留空或填写所问 | 随机生成上卦、下卦与动爻 |
| 04 数字起卦 | 1—6 位数字 | 前后拆分取上下卦，数字和取动爻 |

### 01 · 时起卦

支持的输入示例：

```text
今晚九点，我准备为新角色抽卡，想选一个心绪安定的时间。
明天上午十点，我要参加重要面试，想确认自己的节奏。
今晚七点半，我打算开始学习易经。
Tonight at 9 PM, I plan to draw for a new game character.
Tomorrow at 10 AM, I have an important interview.
```

取数规则：

- 上卦 =（年支数 + 农历月 + 农历日）mod 8
- 下卦 =（年支数 + 农历月 + 农历日 + 时支数）mod 8
- 动爻 =（年支数 + 农历月 + 农历日 + 时支数）mod 6
- 余数为 0 时，按 8 或 6 计

时间表达同时支持以下写法：

- 日期：`2026年10月3日`、`2026-10-03`、`2026/10/03`
- 相对日期：`今天`、`明天`、`后天`、`昨天`、`today`、`tomorrow`、`yesterday`
- 中文时间：`晚上九点`、`七点半`、`巳时`
- 英文时间：`9 PM`、`21:30`

### 02 · 卦象分析

选择本卦、互卦、变卦与动爻，页面会按输入显示完整卦盘，并提示输入的互卦、变卦是否与本卦及动爻推算一致。

- 动爻从最下方的初爻起算，自下而上。
- 动爻在下卦（第 1—3 爻）时，上卦为体、下卦为用。
- 动爻在上卦（第 4—6 爻）时，下卦为体、上卦为用。
- 一致性提示只用于核对输入，不会擅自替换用户选择的卦象。

### 03 · 随机起卦

随机选择上卦（1—8）、下卦（1—8）与动爻（1—6），再按体用规则分析。所问内容仅作为本地阅读记录，不参与随机结果。

### 04 · 数字起卦

本工具采用清晰的拆分规则，和传统任意取数方式可能不同：

- 将数字从中间拆分，前半取上卦数，后半取下卦数；只有一位时上下共用。
- 上下数字分别 mod 8 定卦，余数为 0 按 8 计。
- 所有数字之和 mod 6 定动爻，余数为 0 按 6 计。
- 例如 `202610` 拆为 `202` 与 `610`，数字和为 `11`。

## 结果阅读

结果区包含以下内容：

- **取象时段**：从与体卦关系较顺的时支中选出参考窗口。
- **方位建议**：优先显示生体五行对应的方向。
- **推荐地点**：不再按体卦单卦取象，而是「本卦取形、变卦取用」。本卦上卦定外在空间之形（开阔、半开、明亮、狭长、通透、低处、有高差、平整），本卦下卦定近身坐处之形；变卦上卦定用事（决断、交谈、阅读、启动、传递、独处、收束、整理），变卦下卦定身姿。体势偏弱时，地点只保留形、不给用。
- **三卦卦盘**：展示本卦上下卦、互卦上下卦、变卦上下卦及动爻。
- **五行关系**：以体卦为基准，对木、火、土、金、水五类取象标注生体、比和、克体等关系。
- **象意简析**：综合本卦、互卦、变卦与月令，说明当前取象偏顺或偏弱，并提示保留余量。
- **动爻取意**：先给本卦卦辞与该动爻原文，再给一句白话取意，最后列出六爻全文并高亮动爻。
- **象与应**：结果下方单独一区，含卦象类象、外应观察、万事类卦三张卡片，均按当前卦象选取。

### 五行生克

- 相生：木 → 火 → 土 → 金 → 水 → 木
- 相克：木 → 土 → 水 → 火 → 金 → 木

页面把关系分为五类：

| 内部标识 | 中文显示 | 含义 |
| --- | --- | --- |
| `用生体` | 生体 · 优先 | 外部条件滋养自身 |
| `比和` | 比和 · 同类 | 同气相求，较为平稳 |
| `体克用` | 体克用 · 参考 | 自身可制约外部条件 |
| `体生用` | 体生用 · 有耗 | 自身向外付出，有所消耗 |
| `用克体` | 用克体 · 避免 | 外部条件对自身形成压力 |

### 月令旺衰

月支对应的五行按简化四时法标注为「旺、相、休、囚、死」，用于辅助判断体卦强弱。月支按固定节气日期近似推定，不进行精确天文计算。

## 中英文切换

右上角提供 `中文 / EN` 切换：

- 已生成的卦盘、解析、方位、地点、五行标签和动爻说明会立即切换语言，不会重新起卦。
- 已输入的问题原文保持不变，不会自动翻译，避免改动用户表达。
- 语言偏好写入 `localStorage["xuanqian.lang"]`。
- 所有界面文案集中在脚本内的 `copy.zh` 与 `copy.en` 对象中。
- 六十四卦英文名采用常见英文译名。

## 隐私与数据

- **本地计算**：起卦、农历换算、卦象分析和界面渲染全部在浏览器完成。
- **不上传内容**：没有后端接口，不会把所问内容发送到服务器。
- **本地存储**：只保存语言偏好，不保存所问、卦象或推演历史。
- **刷新页面**：当前结果会消失，需要重新推演。
- **外部链接**：仅抖音、小红书、B 站与邮箱为外链，点击后才离开本地页面。
- **无第三方依赖**：页面不加载外部脚本、字体或图片，核心功能可离线使用。

## 技术说明

### 项目结构

```text
E:\public\xuanqian\
├─ index.html          # 样式、页面结构、文案与推演逻辑
├─ data\               # 资料层，全部为普通 JS 变量，双击即可加载
│  ├─ yaoci.js         # 《周易》六十四卦卦辞与爻辞原文
│  ├─ xiang.js         # 八卦万物类象（象、形、物、人、动、方位、数）
│  ├─ waijing.js       # 外应八类、四档强度、取象八步与记录字段
│  ├─ leigua.js        # 万事类卦十四类，含中英匹配词
│  └─ place.js         # 推荐地点词库（本卦取形 / 变卦取用，含英文简写）
├─ assets\
│  └─ earth-strip.jpg  # 4:1 地球贴图条，供星仪球体自转使用
├─ tools\
│  └─ build-yaoci.py   # 重新抓取并生成 data/yaoci.js 的脚本
└─ README.md           # 本文档
```

资料放在 `data/` 而不是塞进 `index.html`，改类象、补条目、换词库时不必动主文件；用普通 `<script src>` 加载（不是 JSON + fetch），所以双击本地文件也能读，不会触发 file:// 的跨域限制。

`index.html` 仍是零依赖页面：

- CSS 位于 `<style>` 内。
- 原生 JavaScript 位于 `<script>` 内，资料由 `data/` 五个文件提供。
- 无构建工具、框架或包管理依赖。
- 球体自转是纯 CSS：`assets/earth-strip.jpg` 为左右两张 2:1 地图拼成的 4:1 贴图条，子层宽度 400%，`translateX(-50%)` 线性循环，无脚本参与。

### 主要函数

| 函数 | 作用 |
| --- | --- |
| `parseDateTime(raw)` | 解析中英文日期、相对日期与时间表达 |
| `getLunarParts(date)` | 通过 `Intl` 读取农历年、月、日与干支 |
| `getJieqiMonthBranch(date)` | 按近似节气日期推定月支 |
| `createReading()` | 按当前模式生成卦象与体用数据 |
| `renderReading(reading)` | 渲染动态结果，支持切换语言后重绘 |
| `paintYaoText(reading)` | 写入本卦卦辞、动爻原文与六爻列表 |
| `paintNature(reading)` | 按当前卦象渲染类象、外应与万事类卦 |
| `rel(a, b)` | 计算两个五行的生克关系 |
| `setLanguage(lang)` | 切换中英文并更新页面静态/动态内容 |
| `refreshManualCheck()` | 校验手动输入的互卦、变卦是否一致 |

### 常见自定义

- **改配色**：修改 `:root` 中的颜色变量即可全局生效。
- **改界面文字**：修改 `copy.zh` 或 `copy.en` 对应字段。
- **改示例**：修改 `examples` 数组中的 `zh`、`textZh`、`en`、`textEn`。
- **改类象**：编辑 `data/xiang.js`，每个卦一个对象，字段为 `xiang`、`ti`、`xingZhuang`、`se`、`wu`、`ren`、`dong`、`ju`、`ji`、`fang`、`shu`。
- **改外应**：编辑 `data/waijing.js`；`byTrigram` 决定某个卦出现时优先展示哪一门外应。
- **改地点逻辑**：编辑 `data/place.js`；`wai`／`nei` 供本卦，`yong`／`shen` 供变卦。
- **更新爻辞**：运行 `python tools/build-yaoci.py` 重新生成 `data/yaoci.js`，不要手改生成文件。
- **改文案断言**：同步检查中文与英文两套结果模板，避免只改一侧。

## 使用边界

- 本页面用于**文化取象、自我反思与娱乐**，不是算命结论，也不能推定抽卡概率或现实结果。
- 五行、方位与地点建议均为象征取象，不代表实际风险判断；现实行动应以安全、健康、法律和事实信息为准。
- **推荐地点**只是「空间之形 + 用事」的取象用语（如“低处临水、背靠实墙的座位”），不对应任何具体场地，也不构成场地方案或安全评估；实际选点请按现场条件判断。
- **外应**是起卦当下的偶发现象，只能作观察目录与复核提醒；同时出现多个相反解释时，应按「弱」或「无」处理，不强行凑象。
- **万事类卦**的分类由所问字面关键词匹配，归类不准时把它当作邻近视角，而不是结论。
- 卦辞与爻辞原文据《周易》公有领域底本；彖、象、文言未收入，白话取意仅为概述。
- 手动模式会提示三卦不一致，但不会替用户修正卦象。
- 月支按近似的固定节气日期计算，农历转换依赖浏览器实现，不同浏览器在极少数日期上可能有差异。
- 页面不保存历史记录，也不提供账号、云同步或分享功能。
- 英文卦名与释义为便于阅读的常见译法，并非唯一权威译名。
